🟣 STACK

LIFO (Last In, First Out) — jo aakhri mein aaya, wahi sabse pehle nikalta hai.

📘 Part A — Stack Theory & Concepts

Pehle fundamentals clear karo — stack kaam kaise karta hai, C++ mein implement kaise karte hain.

1️⃣ Stack kya hota hai? (LIFO)

Stack ek linear data structure hai jo LIFO (Last In, First Out) principle follow karta hai — jo element sabse aakhri mein insert hua, wahi sabse pehle remove hota hai. Insertion aur deletion dono sirf ek hi end — "top" — se hoti hai.

┌─────────┐ │ 30 │ ← TOP (sabse pehle nikalega) ├─────────┤ │ 20 │ ├─────────┤ │ 10 │ ← Bottom (sabse pehle daala gaya) └─────────┘
Samjho ise aise: Plates ka stack socho — jo plate sabse upar (aakhri mein) rakhi, wahi sabse pehle uthaogi. Neeche wali plate tab tak nahi nikaal sakte jab tak upar wali saari na hata do.
Tip: Stack "recursion" ke bohot close hai — har function call bhi ek call stack mein push/pop hota hai. Isliye recursive solutions ko iterative banane ke liye aksar explicit Stack use hota hai.

2️⃣ Implementation in C++

STL stack (sabse common — LeetCode mein yahi use karo)

#include <stack>
using namespace std;

stack<int> st;
st.push(10);
st.push(20);
st.push(30);

cout << st.top();   // 30
st.pop();             // 30 remove ho jaata hai (return nahi karta!)
cout << st.top();    // 20
cout << st.empty();  // false
cout << st.size();    // 2
Dhyan dein: C++ ka st.pop() koi value return nahi karta — sirf remove karta hai. Value chahiye to pehle st.top() se le lo, phir pop() call karo.

Array/Vector se manual implementation (samajhne ke liye)

class MyStack {
    vector<int> data;
public:
    void push(int x) { data.push_back(x); }
    void pop() { if (!data.empty()) data.pop_back(); }
    int top() { return data.back(); }
    bool empty() { return data.empty(); }
};

Tip: Saari operations O(1) hain — yahi Stack ka sabse bada advantage hai jab bhi "most recent" cheez chahiye ho.

4️⃣ Real-World Applications

  • Function call stack: Recursion internally isi se kaam karta hai
  • Undo/Redo: Text editors, browsers (back button)
  • Expression evaluation: Calculator, compiler (parentheses matching)
  • DFS (Depth First Search): Explicit stack ya recursion se
  • Backtracking algorithms: Maze solving, N-Queens

Pattern 1 — Matching / Validity Check

Signal: "valid parentheses", "matching brackets" — jahan opening symbol ko uske corresponding closing symbol se match karna ho.
🟢 Valid ParenthesesEasy 
bool isValid(string s) {
    stack<char> st;
    unordered_map<char, char> pairs = {{')','('}, {']','['}, {'}','{'}};

    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty() || st.top() != pairs[c]) return false;
            st.pop();
        }
    }
    return st.empty();
}
🟡 Minimum Add to Make Parentheses ValidMedium 
int minAddToMakeValid(string s) {
    int open = 0, additions = 0;
    for (char c : s) {
        if (c == '(') open++;
        else {
            if (open > 0) open--;
            else additions++;
        }
    }
    return additions + open;
}

Yahan counter se bhi kaam ho jaata hai (stack ki zaroorat nahi) — lekin concept same hai: "kitne unmatched open bache hain".

Interview Point: Matching pattern ka core idea: opening symbol push karo, closing symbol pe stack ka top check karo — end mein stack empty honi chahiye.

Pattern 2 — Monotonic Stack

Signal: "next greater/smaller element", "daily temperatures", "largest rectangle in histogram" — jahan har element ke liye "agla bada/chhota" element dhundna ho efficiently.

Template (Next Greater Element)

stack<int> st;   // indices store karte hain
vector<int> result(n, -1);

for (int i = 0; i < n; i++) {
    while (!st.empty() && arr[st.top()] < arr[i]) {
        result[st.top()] = arr[i];   // ye current element hi "next greater" hai
        st.pop();
    }
    st.push(i);
}
🟢 Next Greater Element IEasy 
vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
    unordered_map<int, int> nextGreater;
    stack<int> st;

    for (int num : nums2) {
        while (!st.empty() && st.top() < num) {
            nextGreater[st.top()] = num;
            st.pop();
        }
        st.push(num);
    }

    vector<int> result;
    for (int num : nums1) result.push_back(nextGreater.count(num) ? nextGreater[num] : -1);
    return result;
}
🟡 Daily TemperaturesMedium

"Kitne din baad garam din aayega" — indices ke saath monotonic decreasing stack maintain karo.

vector<int> dailyTemperatures(vector<int>& temps) {
    vector<int> result(temps.size(), 0);
    stack<int> st;   // indices

    for (int i = 0; i < temps.size(); i++) {
        while (!st.empty() && temps[st.top()] < temps[i]) {
            int idx = st.top(); st.pop();
            result[idx] = i - idx;
        }
        st.push(i);
    }
    return result;
}
🔴 Largest Rectangle in HistogramHard

Monotonic increasing stack — jab chhota bar aaye, stack se pop karte hue area calculate karo.

int largestRectangleArea(vector<int>& heights) {
    stack<int> st;   // indices, increasing height order
    int maxArea = 0;
    heights.push_back(0);  // sentinel — end mein sab pop karwane ke liye

    for (int i = 0; i < heights.size(); i++) {
        while (!st.empty() && heights[st.top()] > heights[i]) {
            int height = heights[st.top()]; st.pop();
            int width = st.empty() ? i : i - st.top() - 1;
            maxArea = max(maxArea, height * width);
        }
        st.push(i);
    }
    return maxArea;
}
Interview Point: Monotonic Stack se O(n²) brute force (har element ke liye linear search) O(n) mein aa jaata hai — kyunki har element sirf ek baar push aur ek baar pop hota hai.

Pattern 3 — Expression Evaluation

Signal: "evaluate expression", "basic calculator", "decode string" — jahan operators/nested structure ko sahi order mein process karna ho.
🟡 Evaluate Reverse Polish NotationMedium 
int evalRPN(vector<string>& tokens) {
    stack<int> st;
    for (string& token : tokens) {
        if (token == "+" || token == "-" || token == "*" || token == "/") {
            int b = st.top(); st.pop();
            int a = st.top(); st.pop();
            if (token == "+") st.push(a + b);
            else if (token == "-") st.push(a - b);
            else if (token == "*") st.push(a * b);
            else st.push(a / b);
        } else {
            st.push(stoi(token));
        }
    }
    return st.top();
}
🔴 Basic Calculator (with +, -, parentheses)Hard 
int calculate(string s) {
    stack<int> st;
    int result = 0, num = 0, sign = 1;

    for (char c : s) {
        if (isdigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '+') {
            result += sign * num; num = 0; sign = 1;
        } else if (c == '-') {
            result += sign * num; num = 0; sign = -1;
        } else if (c == '(') {
            st.push(result); st.push(sign);
            result = 0; sign = 1;
        } else if (c == ')') {
            result += sign * num; num = 0;
            result *= st.top(); st.pop();     // pichla sign
            result += st.top(); st.pop();     // pichla result
        }
    }
    return result + sign * num;
}
Tip: Expression evaluation problems mein stack "state save karne" ke liye use hota hai — jab bracket khule to current state push karo, jab bracket band ho to pop karke combine karo.

Pattern 4 — Min/Max Stack Design

Signal: "design a stack that supports getMin/getMax in O(1)" — normal stack ke saath extra info track karna ho.
🟡 Min StackMedium

Do stacks use karo — ek normal values ke liye, ek "abhi tak ka minimum" track karne ke liye.

class MinStack {
    stack<int> st;
    stack<int> minSt;
public:
    void push(int val) {
        st.push(val);
        if (minSt.empty() || val <= minSt.top()) minSt.push(val);
        else minSt.push(minSt.top());
    }
    void pop() {
        st.pop();
        minSt.pop();
    }
    int top() { return st.top(); }
    int getMin() { return minSt.top(); }
};

Sab operations O(1) — har push par minSt bhi update hoti hai, isliye getMin() bhi O(1) mein milta hai.

Interview Point: "Auxiliary stack" trick (ek extra stack alag info track karne ke liye) bohot common design pattern hai — Min Stack, Max Stack, dono isi tarah solve hote hain.

Pattern 5 — Stack for Simulation

Signal: "simulate a process step by step", "asteroid collision", "remove k digits" — jahan har naya element pichle elements se "interact" kar sakta ho.
🟡 Asteroid CollisionMedium

Right-moving asteroids stack mein rakho; jab left-moving aaye, collisions simulate karo.

vector<int> asteroidCollision(vector<int>& asteroids) {
    vector<int> st;   // stack as vector

    for (int a : asteroids) {
        bool alive = true;
        while (alive && a < 0 && !st.empty() && st.back() > 0) {
            if (st.back() < -a) { st.pop_back(); continue; }
            else if (st.back() == -a) { st.pop_back(); }
            alive = false;
        }
        if (alive) st.push_back(a);
    }
    return st;
}
🟡 Remove K Digits (smallest number banao)Medium

Monotonic increasing stack — jab bada digit pichle chhote digit se pehle aaye, chhota digit hata do (agar k bacha ho).

string removeKdigits(string num, int k) {
    string st;   // stack as string
    for (char c : num) {
        while (!st.empty() && k > 0 && st.back() > c) {
            st.pop_back();
            k--;
        }
        st.push_back(c);
    }
    while (k-- > 0) st.pop_back();   // agar k bacha, end se hatao

    int i = 0;
    while (i < st.size() - 1 && st[i] == '0') i++;   // leading zeros hatao
    string result = st.substr(i);
    return result.empty() ? "0" : result;
}
Tip: Simulation pattern mein socho "kya current element pichle stack top ko affect kar sakta hai?" — agar haan, to while loop mein handle karo jab tak stable state na aa jaaye.

🔵 QUEUE

FIFO (First In, First Out) — jo pehle aaya, wahi pehle nikalta hai.

📘 Part A — Queue Theory & Concepts

Pehle fundamentals clear karo — queue kaam kaise karta hai, C++ mein implement kaise karte hain.

1️⃣ Queue kya hota hai? (FIFO)

Queue ek linear data structure hai jo FIFO (First In, First Out) principle follow karta hai — jo element sabse pehle insert hua, wahi sabse pehle remove hota hai. Insertion "rear/back" se, deletion "front" se hoti hai.

FRONT REAR │ │ ▼ ▼ ┌────┬────┬────┬────┐ │ 10 │ 20 │ 30 │ 40 │ ← naya element yahan add hoga (enqueue) └────┴────┴────┴────┘ ↑ yahan se nikalega (dequeue)
Samjho ise aise: Ticket counter ki line socho — jo pehle line mein lagta hai, uski ticket pehle banti hai. Naye log line ke peeche (rear) join karte hain, service front se hoti hai.
Tip: Queue ka Stack se opposite behavior hai — Stack "recent" cheez deta hai, Queue "oldest" cheez deta hai. Isliye BFS (level-by-level) mein Queue use hota hai, DFS mein Stack.

2️⃣ Implementation in C++

STL queue

#include <queue>
using namespace std;

queue<int> q;
q.push(10);    // enqueue — rear mein add
q.push(20);
q.push(30);

cout << q.front();  // 10
q.pop();              // front se remove ho jaata hai
cout << q.front();   // 20
cout << q.empty();   // false
cout << q.size();     // 2

STL deque (Double-Ended Queue — dono ends se operations)

#include <deque>
deque<int> dq;
dq.push_back(10);    // rear se add
dq.push_front(5);     // front se add
dq.pop_back();         // rear se remove
dq.pop_front();        // front se remove
Tip: LeetCode mein "sliding window maximum" jaise problems mein deque bohot use hota hai — dono ends se O(1) operations milte hain.

3️⃣ Core Operations & Complexity

OperationKya karta haiTime
push(x) / enqueueRear mein naya element daaloO(1)
pop() / dequeueFront se element hataoO(1)
front()Front ka element dekhoO(1)
empty()Queue khaali hai kyaO(1)

4️⃣ Types of Queue

Circular Queue

Fixed-size array ko circularly use karta hai — rear end pahunchne ke baad wapas 0th index se use hota hai (space waste nahi hota).

Priority Queue (Heap-based)

#include <queue>
priority_queue<int> maxHeap;               // default: max-heap
priority_queue<int, vector<int>, greater<int>> minHeap;  // min-heap

maxHeap.push(30); maxHeap.push(10); maxHeap.push(20);
cout << maxHeap.top();  // 30 (sabse bada pehle)

Elements FIFO order mein nahi, balki priority ke hisaab se nikalte hain. Internally ye heap data structure hai.

Deque (Double-Ended Queue)

Dono ends se insert/delete O(1) mein — Sliding Window Maximum jaisi problems mein use hota hai.

Pattern 1 — BFS Traversal

Signal: "level order", "shortest path (unweighted)", "minimum number of steps" — jahan level-by-level explore karna ho.

Template

queue<Node*> q;
q.push(start);
visited.insert(start);

while (!q.empty()) {
    Node* curr = q.front(); q.pop();
    // process curr

    for (Node* neighbor : curr->neighbors) {
        if (!visited.count(neighbor)) {
            visited.insert(neighbor);
            q.push(neighbor);
        }
    }
}
🟡 Binary Tree Level Order TraversalMedium 
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int size = q.size();
        vector<int> level;
        for (int i = 0; i < size; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
    }
    return result;
}
Tip: size = q.size() ko loop se pehle save karna hi "level by level" grouping ka trick hai.
🟡 Rotting Oranges (multi-source BFS)Medium

Saare rotten oranges ek saath queue mein daalo (multi-source), phir level-by-level spread karo.

int orangesRotting(vector<vector<int>>& grid) {
    int rows = grid.size(), cols = grid[0].size();
    queue<pair<int,int>> q;
    int fresh = 0;

    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++) {
            if (grid[i][j] == 2) q.push({i, j});
            else if (grid[i][j] == 1) fresh++;
        }

    int minutes = 0;
    vector<pair<int,int>> dirs = {{0,1},{0,-1},{1,0},{-1,0}};

    while (!q.empty() && fresh > 0) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            auto [r, c] = q.front(); q.pop();
            for (auto& [dr, dc] : dirs) {
                int nr = r + dr, nc = c + dc;
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;
                    fresh--;
                    q.push({nr, nc});
                }
            }
        }
        minutes++;
    }
    return fresh == 0 ? minutes : -1;
}
Interview Point: "Shortest path in unweighted graph/grid" dikhte hi BFS socho — Queue guarantee karta hai ki tum nodes ko unki "distance from source" ke increasing order mein visit karo.

Pattern 2 — Monotonic Deque

Signal: "sliding window maximum/minimum" — jahan window slide karte waqt max/min O(1) amortized mein chahiye ho.
🔴 Sliding Window MaximumHard

Deque mein sirf "useful" indices rakho (decreasing value order) — front hamesha current window ka max hota hai.

vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;   // indices store karte hain
    vector<int> result;

    for (int i = 0; i < nums.size(); i++) {
        // window se bahar wale indices hatao
        if (!dq.empty() && dq.front() <= i - k) dq.pop_front();

        // chhote elements peeche se hatao (wo kabhi max nahi banenge)
        while (!dq.empty() && nums[dq.back()] < nums[i]) dq.pop_back();

        dq.push_back(i);

        if (i >= k - 1) result.push_back(nums[dq.front()]);
    }
    return result;
}

Time: O(n) — har index ek baar push aur ek baar pop hota hai.

Interview Point: Ye pattern Array ke "Monotonic Stack" jaisa hi hai, bas deque use hota hai kyunki window ke dono end se elements remove karne padte hain (front se "out of window", back se "chhote elements").

Pattern 3 — Two Stacks ↔ Queue (Design)

Signal: "implement queue using stacks" ya "implement stack using queues" — classic design conversion question.
🟢 Implement Queue using StacksEasy

2 stacks — ek "input" ke liye, ek "output" ke liye. Jab output khaali ho, saara input reverse karke output mein daal do (LIFO se FIFO mil jaata hai).

class MyQueue {
    stack<int> inSt, outSt;
public:
    void push(int x) {
        inSt.push(x);
    }

    int pop() {
        peek();
        int val = outSt.top();
        outSt.pop();
        return val;
    }

    int peek() {
        if (outSt.empty()) {
            while (!inSt.empty()) {
                outSt.push(inSt.top());
                inSt.pop();
            }
        }
        return outSt.top();
    }

    bool empty() {
        return inSt.empty() && outSt.empty();
    }
};

Amortized O(1) per operation — har element max 2 baar move hota hai (in→out) apni poori lifetime mein.

Tip: Ye "amortized complexity" samajhne ke liye best example hai — kabhi kabhi ek operation O(n) legi (jab reverse ho raha ho), but average O(1) hi rehta hai.

Pattern 4 — Priority Queue (Heap)

Signal: "kth largest/smallest", "top k frequent", "merge k sorted lists", "task scheduler" — jahan hamesha "current best/worst" O(log n) mein chahiye ho.
🟡 Kth Largest Element in an ArrayMedium

Size-k ka min-heap maintain karo — heap ka top hamesha "kth largest so far" hoga.

int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> minHeap;

    for (int num : nums) {
        minHeap.push(num);
        if (minHeap.size() > k) minHeap.pop();
    }
    return minHeap.top();
}

Time: O(n log k) — sorting (O(n log n)) se better jab k chhota ho.

🟡 Top K Frequent ElementsMedium 
vector<int> topKFrequent(vector<int>& nums, int k) {
    unordered_map<int, int> freq;
    for (int num : nums) freq[num]++;

    priority_queue<pair<int,int>> pq;   // max-heap by frequency
    for (auto& [num, count] : freq) pq.push({count, num});

    vector<int> result;
    while (k--) {
        result.push_back(pq.top().second);
        pq.pop();
    }
    return result;
}
Interview Point: "Top K" ya "Kth" wale questions mein Priority Queue O(n log k) deta hai, jo full sort (O(n log n)) se better hai jab k << n ho. C++ mein priority_queue<T, vector<T>, greater<T>> min-heap ke liye yaad rakho.

Pattern 5 — Circular Queue Design

Signal: "design a circular queue/buffer with fixed size" — jahan array ko wraparound karke reuse karna ho.
🟡 Design Circular QueueMedium 
class MyCircularQueue {
    vector<int> data;
    int head, count, capacity;
public:
    MyCircularQueue(int k) {
        data.resize(k);
        head = 0; count = 0; capacity = k;
    }

    bool enQueue(int value) {
        if (isFull()) return false;
        int tail = (head + count) % capacity;
        data[tail] = value;
        count++;
        return true;
    }

    bool deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % capacity;
        count--;
        return true;
    }

    int Front() { return isEmpty() ? -1 : data[head]; }
    int Rear() { return isEmpty() ? -1 : data[(head + count - 1) % capacity]; }
    bool isEmpty() { return count == 0; }
    bool isFull() { return count == capacity; }
};

Core trick: % capacity (modulo) se index wraparound karta hai — array ke end tak pahunchne ke baad wapas 0 se use hota hai.

Interview Point: Circular Queue real systems mein bohot use hota hai — jaise CPU scheduling buffers, streaming data buffers — jahan fixed memory reuse karna ho.

⚠️ Common Mistakes & Interview Tips

  • C++ mein stack.pop() aur queue.pop() koi value return nahi karte — pehle top()/front() se le lo
  • Empty stack/queue pe top()/front() call karna — undefined behavior, hamesha empty() check karo
  • BFS mein visited set update karna bhool jaana — infinite loop ya duplicate processing ho sakti hai
  • Monotonic Stack/Deque mein condition (< vs <=) galat rakhna — duplicate handling change ho jaati hai
  • Priority Queue mein max-heap vs min-heap comparator confuse karna — greater<int> min-heap deta hai, default max-heap hota hai
  • Level order BFS mein q.size() ko loop shuru hone se pehle save na karna — level boundaries mix ho jaate hain
Dhyan dein: Stack/Queue design problems mein hamesha edge cases (empty, full, single element) explicitly test karo.

🧠 Quick Revision — Click to Reveal

Stack DFS ke liye aur Queue BFS ke liye kyun use hota hai?
Stack (LIFO) sabse recently discovered node ko pehle explore karta hai — isse "deep" jaate ho (DFS). Queue (FIFO) sabse purane discovered nodes ko pehle process karta hai — isse "level by level" (BFS) explore hota hai.
Monotonic Stack aur normal Stack mein kya farak hai?
Monotonic Stack hamesha ek order maintain karta hai (increasing ya decreasing) — naya element push karne se pehle stack se "invalid" elements pop kar diye jaate hain. Ye "next greater/smaller" type problems ke liye O(n) solution deta hai.
Priority Queue internally kaise kaam karta hai?
Internally ek Binary Heap hota hai (array-based complete binary tree). Insert aur delete dono O(log n) mein hote hain, top/peek O(1) mein.
Deque, Stack aur Queue dono ka kaam kar sakta hai kya?
Haan — Deque (double-ended queue) dono ends se O(1) push/pop deta hai, isliye ye Stack (ek end use karke) aur Queue (dono ends use karke) dono ki tarah behave kar sakta hai. Isliye Monotonic Deque jaise patterns mein use hota hai.
