📘 Part A — Basic Theory & Concepts

Pehle fundamentals clear karo — node kya hai, types kya hain, basic operations kaise likhte hain. Ye foundation Part B ke patterns samajhne ke liye zaroori hai.

1️⃣ Linked List kya hota hai?

Linked List ek linear data structure hai jisme elements (nodes) memory mein contiguous nahi hote. Har node do cheezein rakhta hai — data aur next node ka address (pointer).

HEAD │ ▼ ┌──────┬──────┐ ┌──────┬──────┐ ┌──────┬──────┐ │ 10 │ ●───┼────▶│ 20 │ ●───┼────▶│ 30 │ NULL │ └──────┴──────┘ └──────┴──────┘ └──────┴──────┘ Node 1 Node 2 Node 3
Samjho ise aise: Treasure hunt ki tarah — har clue (node) apna hint (data) aur "agla clue kahan hai" (address) deta hai. Directly 5th clue pe jump nahi kar sakte, 1st se follow karna padta hai.
📌 Real-life Examples dekho
  • Music player playlist — next song ka reference
  • Browser history — back/forward navigation (doubly LL)
  • Train bogies — har bogie next se connected
  • LRU/LFU Cache — Doubly LL + HashMap
  • Hash Map collisions — chaining ke liye linked list
Tip: "Linear" hai array jaisa (order maintain karta hai), par memory mein "linked" hai — isliye random access nahi milta, sirf sequential.

5️⃣ Basic Operations — Traversal, Insertion, Deletion

Traversal

void traverse(ListNode* head) {
    ListNode* temp = head;
    while (temp != nullptr) {
        cout << temp->val << " ";
        temp = temp->next;
    }
}

Length & Search

int length(ListNode* head) {
    int count = 0;
    ListNode* temp = head;
    while (temp) { count++; temp = temp->next; }
    return count;
}

int search(ListNode* head, int key) {
    ListNode* temp = head;
    int pos = 0;
    while (temp) {
        if (temp->val == key) return pos;
        temp = temp->next;
        pos++;
    }
    return -1;
}
➕ Insertion — Beginning / End / Position 
// Insert at Beginning — O(1)
ListNode* insertAtHead(ListNode* head, int val) {
    ListNode* newNode = new ListNode(val);
    newNode->next = head;
    return newNode;
}

// Insert at End — O(n)
ListNode* insertAtEnd(ListNode* head, int val) {
    ListNode* newNode = new ListNode(val);
    if (head == nullptr) return newNode;
    ListNode* temp = head;
    while (temp->next != nullptr) temp = temp->next;
    temp->next = newNode;
    return head;
}

// Insert at Position — O(n)
ListNode* insertAtPos(ListNode* head, int pos, int val) {
    ListNode* newNode = new ListNode(val);
    if (pos == 0) { newNode->next = head; return newNode; }
    ListNode* temp = head;
    for (int i = 0; i < pos - 1; i++) temp = temp->next;
    newNode->next = temp->next;
    temp->next = newNode;
    return head;
}
Tip: Agar tail pointer maintain karo to "insert at end" O(1) mein ho sakta hai.
➖ Deletion — Beginning / By Value 
// Delete from Beginning — O(1)
ListNode* deleteHead(ListNode* head) {
    if (head == nullptr) return nullptr;
    ListNode* newHead = head->next;
    delete head;
    return newHead;
}

// Delete by Value — O(n)
ListNode* deleteByValue(ListNode* head, int val) {
    if (!head) return nullptr;
    if (head->val == val) {
        ListNode* newHead = head->next;
        delete head;
        return newHead;
    }
    ListNode* temp = head;
    while (temp->next && temp->next->val != val) temp = temp->next;
    if (temp->next) {
        ListNode* toDelete = temp->next;
        temp->next = temp->next->next;
        delete toDelete;
    }
    return head;
}
Dhyan dein: Delete se pehle hamesha next reference save karo, warna list break ho sakti hai.

6️⃣ Doubly Linked List — Full Operations

DoublyListNode* insertAtHead(DoublyListNode* head, int val) {
    DoublyListNode* n = new DoublyListNode(val);
    n->next = head;
    if (head != nullptr) head->prev = n;
    return n;
}

void deleteNode(DoublyListNode* node) {
    if (node->prev != nullptr) node->prev->next = node->next;
    if (node->next != nullptr) node->next->prev = node->prev;
}
Samjho ise aise: DLL train ki bogies jaisi hai — aage-peeche dono hooks hote hain, isliye beech ki bogie hatani ho to sirf uske dono connections jodne padte hain.

Pattern 1 — Dummy Node Technique

Signal: Jab HEAD khud change ho sakta hai (delete/insert operations jo pehle node ko affect karein) — edge cases handle karne ke liye ek fake "dummy" node lagao jo asli head se pehle aata hai.

Template

ListNode* dummy = new ListNode(-1);
dummy->next = head;
ListNode* curr = dummy;

// ... operations curr ke through karo ...

return dummy->next;  // asli naya head
DUMMY -> HEAD -> 1 -> 2 -> 3 -> NULL ↑ isse hamesha ek "safe" starting point milta hai
🟢 Remove Linked List ElementsEasy

Sabhi nodes jinki value val ke barabar hai, unhe delete karo.

ListNode* removeElements(ListNode* head, int val) {
    ListNode* dummy = new ListNode(-1);
    dummy->next = head;
    ListNode* curr = dummy;

    while (curr->next != nullptr) {
        if (curr->next->val == val) {
            curr->next = curr->next->next;
        } else {
            curr = curr->next;
        }
    }
    return dummy->next;
}

Time: O(n)   Space: O(1)

🟡 Remove Nth Node From EndMedium

Dummy node + two pointer gap technique (Pattern 4 se combine).

ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode* dummy = new ListNode(-1);
    dummy->next = head;
    ListNode* fast = dummy;
    ListNode* slow = dummy;

    for (int i = 0; i < n; i++) fast = fast->next;

    while (fast->next != nullptr) {
        fast = fast->next;
        slow = slow->next;
    }
    slow->next = slow->next->next;
    return dummy->next;
}

Time: O(n)   Space: O(1)   — single pass mein solve hota hai

🟡 Partition ListMedium

List ko x se chhote aur x se bade/barabar mein partition karo, order maintain karke. Do dummy lists banao aur end mein join karo.

ListNode* partition(ListNode* head, int x) {
    ListNode* smallDummy = new ListNode(-1);
    ListNode* bigDummy = new ListNode(-1);
    ListNode* small = smallDummy;
    ListNode* big = bigDummy;

    while (head != nullptr) {
        if (head->val < x) {
            small->next = head;
            small = small->next;
        } else {
            big->next = head;
            big = big->next;
        }
        head = head->next;
    }
    big->next = nullptr;      // zaroori hai warna cycle ban sakta hai
    small->next = bigDummy->next;
    return smallDummy->next;
}
Interview Point: Jis bhi problem mein "head delete ho sakta hai" ya "multiple lists merge karke ek banani hai", wahan dummy node laga do — code bohot clean ho jaata hai aur edge case bugs kam hote hain.

Pattern 2 — Fast & Slow Pointer (Floyd's)

Signal: "middle", "cycle/loop detect", "palindrome", "happy number" — jahan bhi list ko ek hi pass mein 2 alag speed se traverse karna ho.

Template

ListNode* slow = head;
ListNode* fast = head;

while (fast != nullptr && fast->next != nullptr) {
    slow = slow->next;
    fast = fast->next->next;
    // yahan slow == fast check karke cycle detect kar sakte ho
}
// loop khatam hone par slow = middle node hota hai
🟢 Middle of the Linked ListEasy 
ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
🟢 Linked List CycleEasy 
bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
🟡 Linked List Cycle II (cycle ka start point)Medium

Pehle meeting point dhundo, phir ek pointer HEAD se, dusra meeting point se — same speed se chalao, jahan milein wahi cycle start hai.

ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    bool cyclePresent = false;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) { cyclePresent = true; break; }
    }
    if (!cyclePresent) return nullptr;

    slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
    return slow;
}
🟢 Palindrome Linked ListEasy

Middle dhundo → dusra half reverse karo (Pattern 3) → compare karo.

bool isPalindrome(ListNode* head) {
    if (!head || !head->next) return true;

    // Step 1: middle dhundo
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // Step 2: dusra half reverse karo
    ListNode* prev = nullptr;
    ListNode* curr = slow;
    while (curr) {
        ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }

    // Step 3: compare karo
    ListNode* p1 = head;
    ListNode* p2 = prev;
    while (p2) {
        if (p1->val != p2->val) return false;
        p1 = p1->next;
        p2 = p2->next;
    }
    return true;
}

Time: O(n)   Space: O(1) — ye 3 patterns (fast-slow + reversal + two pointer compare) ka combo hai.

Tip: Fast-slow pointer aksar akela nahi aata — palindrome jaise questions mein iske saath Pattern 3 (Reversal) bhi combine hota hai. Combos pehchan na seekho.

Pattern 3 — In-place Reversal

Signal: "reverse", "reverse between L and R", "reverse in groups of K" — jab bhi pointers ki direction palatni ho, extra space use kiye bina.

Template (3-pointer technique)

ListNode* prev = nullptr;
ListNode* curr = head;

while (curr != nullptr) {
    ListNode* nextTemp = curr->next;  // 1. next save karo
    curr->next = prev;                // 2. link reverse karo
    prev = curr;                      // 3. prev aage badhao
    curr = nextTemp;                  // 4. curr aage badhao
}
// prev ab naya head hai
🟢 Reverse Linked ListEasy 
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr != nullptr) {
        ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}
🟡 Reverse Linked List II (position left se right tak)Medium

Sirf left..right range reverse karni hai, baaki list waisi hi rehni chahiye.

ListNode* reverseBetween(ListNode* head, int left, int right) {
    ListNode* dummy = new ListNode(-1);
    dummy->next = head;
    ListNode* prev = dummy;

    for (int i = 0; i < left - 1; i++) prev = prev->next;

    ListNode* curr = prev->next;
    for (int i = 0; i < right - left; i++) {
        ListNode* nextTemp = curr->next;
        curr->next = nextTemp->next;
        nextTemp->next = prev->next;
        prev->next = nextTemp;
    }
    return dummy->next;
}

Trick: "insert front" technique — har node ko range ke start pe le aao (dummy node ke saath combine).

🔴 Reverse Nodes in k-GroupHard

Pehle check karo K nodes available hain, tabhi reverse karo — recursion se agla group solve karo.

ListNode* reverseKGroup(ListNode* head, int k) {
    ListNode* curr = head;
    int count = 0;
    while (curr != nullptr && count < k) {
        curr = curr->next;
        count++;
    }
    if (count < k) return head;   // group incomplete, chhod do

    ListNode* prev = reverseKGroup(curr, k);  // agla group pehle solve
    curr = head;
    while (count-- > 0) {
        ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}
Interview Point: Reversal pattern ka base "3-pointer template" itna important hai ki isse bina dekhe likhna aana chahiye — 80% reversal-based hard problems isi template ka extension hote hain.

Pattern 4 — Two Pointer with Gap

Signal: "nth from end", "intersection of two lists", "rotate list" — jahan do pointers ko fix gap ya smart switching ke through synchronize karna ho.
🟢 Intersection of Two Linked ListsEasy

Dono pointers apni list khatam hone pe dusri list ke head pe switch ho jaate hain — length difference automatically balance ho jaata hai.

ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
    if (!headA || !headB) return nullptr;
    ListNode* a = headA;
    ListNode* b = headB;

    while (a != b) {
        a = (a == nullptr) ? headB : a->next;
        b = (b == nullptr) ? headA : b->next;
    }
    return a;   // intersection node ya nullptr
}
🟡 Rotate ListMedium

List ko circular banao, phir sahi jagah se todo.

ListNode* rotateRight(ListNode* head, int k) {
    if (!head || !head->next || k == 0) return head;

    int len = 1;
    ListNode* tail = head;
    while (tail->next) { tail = tail->next; len++; }

    k = k % len;
    if (k == 0) return head;

    tail->next = head;               // circular bana do
    int stepsToNewTail = len - k;
    ListNode* newTail = head;
    for (int i = 1; i < stepsToNewTail; i++) newTail = newTail->next;

    ListNode* newHead = newTail->next;
    newTail->next = nullptr;         // break karo
    return newHead;
}
Tip: "Nth from end" wale saare problems mein soch lo — "gap of N banao, phir dono ek saath chalao" — ye ek hi core idea baar baar reuse hota hai.

Pattern 5 — Merge Technique

Signal: "merge two sorted lists", "merge k sorted lists", "sort list" — jahan do ya zyada sorted lists ko combine karna ho.

Template — Merge Two Sorted Lists

ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode* dummy = new ListNode(-1);
    ListNode* tail = dummy;

    while (l1 != nullptr && l2 != nullptr) {
        if (l1->val <= l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    tail->next = (l1 != nullptr) ? l1 : l2;
    return dummy->next;
}
🔴 Merge k Sorted ListsHard

Divide & conquer se pairs mein merge karte jao — jaise merge sort mein hota hai.

ListNode* mergeKLists(vector<ListNode*>& lists) {
    if (lists.empty()) return nullptr;
    while (lists.size() > 1) {
        vector<ListNode*> merged;
        for (int i = 0; i < lists.size(); i += 2) {
            ListNode* l1 = lists[i];
            ListNode* l2 = (i + 1 < lists.size()) ? lists[i + 1] : nullptr;
            merged.push_back(mergeTwoLists(l1, l2));
        }
        lists = merged;
    }
    return lists[0];
}

Time: O(N log k) jahan N total nodes hain aur k number of lists

🟡 Sort List (Merge Sort on LL)Medium

Fast-slow pointer se list split karo (Pattern 2), recursively sort karo, phir merge karo (Pattern 5).

ListNode* sortList(ListNode* head) {
    if (!head || !head->next) return head;

    ListNode* slow = head;
    ListNode* fast = head->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    ListNode* mid = slow->next;
    slow->next = nullptr;

    ListNode* left = sortList(head);
    ListNode* right = sortList(mid);
    return mergeTwoLists(left, right);
}
Interview Point: "Merge k Sorted Lists" ko heap (priority_queue) se O(N log k) mein bhi solve kar sakte ho — dono approaches jaanna interview mein plus point hai.

Pattern 6 — Recursion on Linked List

Signal: Jab problem "list ke chhote version pe solve karke wapas combine" karne se solve ho — reverse, add numbers, flatten jaise problems mein.
🟢 Reverse Linked List (Recursive version)Easy 
ListNode* reverseList(ListNode* head) {
    if (!head || !head->next) return head;

    ListNode* newHead = reverseList(head->next);
    head->next->next = head;
    head->next = nullptr;
    return newHead;
}

Space: O(n) call stack ki wajah se — iterative version O(1) leta hai.

🟡 Add Two NumbersMedium

Numbers reverse order mein linked list mein stored hain — carry track karte hue add karo.

ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
    ListNode* dummy = new ListNode(-1);
    ListNode* curr = dummy;
    int carry = 0;

    while (l1 != nullptr || l2 != nullptr || carry != 0) {
        int sum = carry;
        if (l1) { sum += l1->val; l1 = l1->next; }
        if (l2) { sum += l2->val; l2 = l2->next; }

        carry = sum / 10;
        curr->next = new ListNode(sum % 10);
        curr = curr->next;
    }
    return dummy->next;
}
🟡 Flatten a Multilevel Doubly Linked ListMedium 
Node* flatten(Node* head) {
    Node* curr = head;
    while (curr != nullptr) {
        if (curr->child != nullptr) {
            Node* next = curr->next;
            Node* childHead = flatten(curr->child);

            curr->next = childHead;
            childHead->prev = curr;
            curr->child = nullptr;

            Node* tail = childHead;
            while (tail->next != nullptr) tail = tail->next;

            tail->next = next;
            if (next != nullptr) next->prev = tail;
        }
        curr = curr->next;
    }
    return head;
}
Dhyan dein: Recursion likhne se pehle 2 cheezein sochlo — base case kya hai (kab rukna hai) aur recursive call ke baad kya combine karna hai. Ye pattern har recursive LL problem mein repeat hota hai.

Pattern 7 — HashMap / HashSet on Linked List

Signal: "clone with random pointer", "duplicate detect", jab O(n) extra space allowed ho aur node-to-node mapping chahiye ho.
🟡 Copy List with Random PointerMedium

HashMap mein original node → clone node ka mapping store karo, phir dono passes mein next/random set karo.

Node* copyRandomList(Node* head) {
    if (!head) return nullptr;
    unordered_map<Node*, Node*> mp;

    Node* curr = head;
    while (curr) {
        mp[curr] = new Node(curr->val);
        curr = curr->next;
    }

    curr = head;
    while (curr) {
        mp[curr]->next = mp[curr->next];
        mp[curr]->random = mp[curr->random];
        curr = curr->next;
    }
    return mp[head];
}

Time: O(n)   Space: O(n) — HashMap ki wajah se. O(1) space wala interleaving trick harder variant hai.

🟢 Linked List Cycle (HashSet approach)Easy

Fast-slow se alag, "visited node" HashSet mein daal ke bhi cycle detect kar sakte ho — thoda extra space lagta hai, but samajhna easy hai.

bool hasCycle(ListNode* head) {
    unordered_set<ListNode*> visited;
    ListNode* curr = head;
    while (curr) {
        if (visited.count(curr)) return true;
        visited.insert(curr);
        curr = curr->next;
    }
    return false;
}
Tip: Interview mein pehle HashMap approach batao (samajhne mein easy), phir bolo "O(1) space mein bhi ho sakta hai" — isse pata chalta hai tumhe dono trade-offs ka pata hai.

Pattern 8 — Linked List based Design

Signal: "design", "LRU Cache", "LFU Cache" — jahan Doubly Linked List + HashMap combine karke O(1) operations chahiye hote hain.
🟡 LRU CacheMedium

DLL se use-order maintain karo (head = most recent, tail = least recent), HashMap se O(1) mein node dhundo.

class LRUCache {
    struct Node {
        int key, val;
        Node* prev; Node* next;
        Node(int k, int v) : key(k), val(v), prev(nullptr), next(nullptr) {}
    };

    int capacity;
    unordered_map<int, Node*> mp;
    Node* head; Node* tail;

    void remove(Node* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }
    void insertAtHead(Node* node) {
        node->next = head->next;
        node->prev = head;
        head->next->prev = node;
        head->next = node;
    }

public:
    LRUCache(int cap) {
        capacity = cap;
        head = new Node(-1, -1);
        tail = new Node(-1, -1);
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        if (mp.find(key) == mp.end()) return -1;
        Node* node = mp[key];
        remove(node);
        insertAtHead(node);
        return node->val;
    }

    void put(int key, int value) {
        if (mp.find(key) != mp.end()) {
            remove(mp[key]);
            mp.erase(key);
        }
        if (mp.size() == capacity) {
            Node* lru = tail->prev;
            remove(lru);
            mp.erase(lru->key);
            delete lru;
        }
        Node* newNode = new Node(key, value);
        insertAtHead(newNode);
        mp[key] = newNode;
    }
};

get() aur put() dono O(1) — ye pattern top asked design question hai (Amazon, Google, Microsoft).

Interview Point: LRU Cache banate waqt dummy head + dummy tail dono use karo (jaisa Pattern 1 mein tha) — isse edge cases (empty cache, single node) automatically handle ho jaate hain.

⚠️ Common Mistakes & Interview Tips

  • NULL check bhool jaana — hamesha edge cases pehle handle karo
  • Delete se pehle next save na karna → list break
  • Circular LL mein while(temp != nullptr) use karna → infinite loop
  • Reversal mein pointer update order galat rakhna
  • Dummy node use na karna jab head khud change ho sakta ho
  • Fast pointer condition mein fast->next check bhool jaana → crash (segfault)
Dhyan dein: Interview mein pehle diagram bana kar dry run karo — pointer manipulation visualize kiye bina galti hona common hai.

Dummy Node hamesha use karna chahiye kya?
Nahi — sirf tab jab head khud change ho sakta ho (delete/insert at start ya multiple merges). Simple traversal-only problems mein zaroorat nahi.
Iterative vs Recursive reversal — interview mein kya bolna better hai?
Dono bata do. Iterative O(1) space leta hai (better), Recursive O(n) space leta hai but code chhota hota hai. Interviewer trade-off jaanna chahta hai.
HashMap approach kab avoid karni chahiye?
Jab interviewer explicitly O(1) space maange, ya "follow-up: can you do it without extra space?" pooche — tab pointer-based (fast-slow, reversal) approach use karo.
