📘 Part A — Basic Theory & Concepts

Pehle fundamentals clear karo — string memory mein kaise store hoti hai, built-in functions, character manipulation. Ye foundation Part B ke patterns samajhne ke liye zaroori hai.

1️⃣ String kya hoti hai?

C++ mein string characters ka ek sequence hai, jo internally char array ki tarah hi contiguous memory mein store hoti hai. C++ ki std::string class (STL) automatically memory manage karti hai — size dynamic hoti hai, jaise vector<char>.

Index: 0 1 2 3 4 ┌────┬────┬────┬────┬────┐ String: │ 'h'│ 'e'│ 'l'│ 'l'│ 'o'│ └────┴────┴────┴────┴────┘
Samjho ise aise: String ek Array hi hai, bas isme char elements hote hain aur STL kuch extra helper functions (substr, find, compare) provide karta hai. Isliye jo patterns Array pe kaam karte hain (Two Pointers, Sliding Window), wahi String pe bhi seedhe apply hote hain.
#include <string>
using namespace std;

string s = "hello";
cout << s.length();     // 5, string ki size
cout << s[0];             // 'h', index se access — O(1)

2️⃣ C++ string: Mutable hai

Java/Python ke unlike, C++ ki std::string mutable hai — matlab tum directly characters modify kar sakte ho bina naya string banaye.

string s = "hello";
s[0] = 'H';        // valid — s ab "Hello" hai
s += " world";     // concatenation, in-place grow hota hai
Tip: Ye C++ ka bada advantage hai — string problems mein tum in-place modification (jaise reverse, swap characters) kar sakte ho bina extra space liye, jo Java/Python mein possible nahi (unke strings immutable hain).

3️⃣ Useful Built-in Functions

string s = "hello world";

s.length();              // ya s.size() -> 11
s.substr(6);              // "world" (index 6 se end tak)
s.substr(0, 5);           // "hello" (index 0 se 5 characters)
s.find("world");          // 6 (index jahan mila), agar na mile to string::npos
s.find("xyz");             // string::npos

reverse(s.begin(), s.end());   // in-place reverse (algorithm header)
sort(s.begin(), s.end());       // in-place sort characters

s.append("!");            // s += "!" jaisa hi
s.erase(0, 6);              // "hello " hata do, "world" bache
s.insert(5, "!!!");        // position 5 pe insert

stoi("123");                // string -> int
to_string(123);             // int -> string

s.push_back('!');           // end mein character add
s.pop_back();                // end se character remove
Tip: #include <string> aur #include <algorithm> dono include karo — reverse(), sort() jaise functions algorithm header mein hain.

4️⃣ Traversal, Comparison & Concatenation

Traversal

for (int i = 0; i < s.length(); i++) cout << s[i];
for (char c : s) cout << c;   // range-based (cleaner)

Comparison

string a = "apple", b = "banana";
if (a == b) { /* equal */ }
if (a < b) { /* lexicographically pehle -- operator overload hai */ }
a.compare(b);   // 0 agar equal, negative agar ab

Concatenation

string a = "hello", b = "world";
string c = a + " " + b;   // "hello world"
a += "!";                  // in-place append
Dhyan dein: Loop ke andar baar-baar result += s[i] karna theek hai (amortized O(1) per append), lekin repeated result = result + s[i] (naya string banate rehna) O(n²) ho sakta hai bade strings mein.

5️⃣ Character & ASCII Manipulation

char c = 'a';
int ascii = (int)c;          // 97

// lowercase to uppercase
char upper = toupper(c);     // 'A'
char lower = tolower('B');    // 'b'

// digit check
isdigit('5');    // true
isalpha('a');     // true
isalnum('9');     // true (alphanumeric)

// character to digit
char d = '7';
int num = d - '0';    // 7  (ASCII trick)

// frequency array (26 lowercase letters ke liye)
int freq[26] = {0};
freq[c - 'a']++;   // 'a' ka index 0, 'b' ka 1, ...
Interview Point: char - '0' aur char - 'a' ye 2 tricks bohot bar-bar use hoti hain — digit ko number mein convert karna, aur letter ko 0-25 index mein map karna (frequency array ke liye).

Pattern 1 — Two Pointers

Signal: "palindrome check", "reverse string", string ke dono ends se ek saath compare/move karna ho.

Template

int left = 0, right = s.length() - 1;
while (left < right) {
    // check / swap karo
    left++; right--;
}
🟢 Valid PalindromeEasy 
bool isPalindrome(string s) {
    int left = 0, right = s.size() - 1;
    while (left < right) {
        if (!isalnum(s[left])) { left++; continue; }
        if (!isalnum(s[right])) { right--; continue; }
        if (tolower(s[left]) != tolower(s[right])) return false;
        left++; right--;
    }
    return true;
}
🟢 Reverse String (in-place)Easy 
void reverseString(vector<char>& s) {
    int left = 0, right = s.size() - 1;
    while (left < right) {
        swap(s[left], s[right]);
        left++; right--;
    }
}
🟡 Valid Palindrome II (ek character remove karke)Medium

Mismatch milte hi 2 possibilities try karo — left skip karke ya right skip karke.

bool isPalin(string& s, int left, int right) {
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++; right--;
    }
    return true;
}

bool validPalindrome(string s) {
    int left = 0, right = s.size() - 1;
    while (left < right) {
        if (s[left] != s[right]) {
            return isPalin(s, left + 1, right) || isPalin(s, left, right - 1);
        }
        left++; right--;
    }
    return true;
}
Tip: String ke Two Pointers Array wale se same hi hain — sirf data type char hai. Concept transfer directly hota hai.

Pattern 2 — Sliding Window

Signal: "longest/shortest substring with condition", "minimum window containing all characters", "anagram in string" — jab ek contiguous window ko slide karna ho.

Template

unordered_map<char, int> window;
int left = 0;
for (int right = 0; right < s.size(); right++) {
    window[s[right]]++;    // window mein s[right] add karo

    while (/* window invalid */) {
        window[s[left]]--;  // window se s[left] remove karo
        left++;
    }
    // yahan window valid hai — answer update karo
}
🟡 Longest Substring Without Repeating CharactersMedium 
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> lastSeen;
    int left = 0, maxLen = 0;

    for (int right = 0; right < s.size(); right++) {
        if (lastSeen.count(s[right]) && lastSeen[s[right]] >= left) {
            left = lastSeen[s[right]] + 1;
        }
        lastSeen[s[right]] = right;
        maxLen = max(maxLen, right - left + 1);
    }
    return maxLen;
}
🟢 Find All Anagrams in a StringMedium

Fixed-size window (size = p.length()) — frequency array se compare karo.

vector<int> findAnagrams(string s, string p) {
    vector<int> result;
    if (s.size() < p.size()) return result;

    vector<int> pCount(26, 0), sCount(26, 0);
    for (char c : p) pCount[c - 'a']++;

    for (int i = 0; i < s.size(); i++) {
        sCount[s[i] - 'a']++;
        if (i >= p.size()) sCount[s[i - p.size()] - 'a']--;
        if (i >= p.size() - 1 && sCount == pCount) result.push_back(i - p.size() + 1);
    }
    return result;
}
🔴 Minimum Window SubstringHard

Variable-size window — pehle expand karo jab tak sab characters cover na ho jayein, phir shrink karo minimum window dhundne ke liye.

string minWindow(string s, string t) {
    unordered_map<char, int> need;
    for (char c : t) need[c]++;

    unordered_map<char, int> window;
    int left = 0, required = need.size(), formed = 0;
    int bestLen = INT_MAX, bestStart = 0;

    for (int right = 0; right < s.size(); right++) {
        char c = s[right];
        window[c]++;
        if (need.count(c) && window[c] == need[c]) formed++;

        while (formed == required) {
            if (right - left + 1 < bestLen) {
                bestLen = right - left + 1;
                bestStart = left;
            }
            char lc = s[left];
            window[lc]--;
            if (need.count(lc) && window[lc] < need[lc]) formed--;
            left++;
        }
    }
    return bestLen == INT_MAX ? "" : s.substr(bestStart, bestLen);
}
Interview Point: Sliding Window String problems mein aksar frequency map (array ya hashmap) ke saath combine hota hai — window ke andar characters ka count track karna padta hai.

Pattern 3 — Hashing / Frequency Count

Signal: "anagram check", "first unique character", "character frequency" — jahan characters ka count track karna ho.
🟢 Valid AnagramEasy 
bool isAnagram(string s, string t) {
    if (s.size() != t.size()) return false;
    vector<int> count(26, 0);
    for (char c : s) count[c - 'a']++;
    for (char c : t) count[c - 'a']--;
    for (int x : count) if (x != 0) return false;
    return true;
}
🟢 First Unique Character in a StringEasy 
int firstUniqChar(string s) {
    vector<int> count(26, 0);
    for (char c : s) count[c - 'a']++;
    for (int i = 0; i < s.size(); i++)
        if (count[s[i] - 'a'] == 1) return i;
    return -1;
}
🟡 Longest Palindrome (build from chars)Easy

Har character jiska count even hai use pura use kar sakte ho; odd wale mein se 1 extra character center mein use ho sakta hai.

int longestPalindrome(string s) {
    unordered_map<char, int> count;
    for (char c : s) count[c]++;

    int length = 0;
    bool hasOdd = false;
    for (auto& [ch, cnt] : count) {
        length += (cnt / 2) * 2;
        if (cnt % 2 == 1) hasOdd = true;
    }
    return hasOdd ? length + 1 : length;
}
Tip: Sirf lowercase letters hon to vector<int>(26, 0) array HashMap se fast hota hai (fixed size, no hashing overhead) — jab bhi range pata ho, array prefer karo.

Pattern 4 — Sorting-based

Signal: "group anagrams", "check if one string is permutation of another" — jahan characters/strings ko sort karke compare karna simplify kare.
🟡 Group AnagramsMedium

Har string ko sort karo — sorted version hi HashMap ki "key" ban jaati hai, sab anagrams same key share karenge.

vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;
    for (string& s : strs) {
        string key = s;
        sort(key.begin(), key.end());
        groups[key].push_back(s);
    }

    vector<vector<string>> result;
    for (auto& [key, group] : groups) result.push_back(group);
    return result;
}
🟡 Sort Characters By FrequencyMedium 
string frequencySort(string s) {
    unordered_map<char, int> freq;
    for (char c : s) freq[c]++;

    vector<pair<char,int>> chars(freq.begin(), freq.end());
    sort(chars.begin(), chars.end(), [](auto& a, auto& b) {
        return a.second > b.second;
    });

    string result;
    for (auto& [ch, count] : chars)
        result += string(count, ch);
    return result;
}
Interview Point: "Sort as key" trick (jaise Group Anagrams mein) bohot common hai — do strings same "signature" share karte hain to unhe group karne ka ek elegant tareeka hai.

Pattern 5 — Stack-based

Signal: "valid parentheses", "decode string", "remove adjacent duplicates" — jahan nested/matching structure ho ya "undo last action" jaisa behavior chahiye ho.
🟢 Valid ParenthesesEasy 
bool isValid(string s) {
    stack<char> st;
    unordered_map<char, char> pairs = {{')','('}, {']','['}, {'}','{'}};

    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty() || st.top() != pairs[c]) return false;
            st.pop();
        }
    }
    return st.empty();
}
🟢 Remove All Adjacent Duplicates in StringEasy 
string removeDuplicates(string s) {
    string st;   // string ko hi stack ki tarah use kar rahe hain
    for (char c : s) {
        if (!st.empty() && st.back() == c) {
            st.pop_back();
        } else {
            st.push_back(c);
        }
    }
    return st;
}
🟡 Decode StringMedium

2 stacks use karo — ek numbers ke liye, ek strings ke liye. [ pe push karo, ] pe pop karke decode karo.

string decodeString(string s) {
    stack<int> counts;
    stack<string> strs;
    string current = "";
    int num = 0;

    for (char c : s) {
        if (isdigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '[') {
            counts.push(num);
            strs.push(current);
            num = 0;
            current = "";
        } else if (c == ']') {
            int repeatTimes = counts.top(); counts.pop();
            string prev = strs.top(); strs.pop();
            string temp = current;
            for (int i = 0; i < repeatTimes; i++) prev += temp;
            current = prev;
        } else {
            current += c;
        }
    }
    return current;
}
Tip: Jab bhi "matching pairs" ya "nested structure undo karna" jaisa lage, Stack pehla option socho — LIFO order isi tarah ke problems ke liye perfect fit hai.

Pattern 6 — Dynamic Programming on Strings

Signal: "longest common subsequence", "edit distance", "longest palindromic substring" — jahan 2D table se overlapping subproblems solve hote hain.
🟡 Longest Palindromic SubstringMedium

"Expand around center" approach — har index (aur har gap) ko center maan ke dono taraf expand karo.

string longestPalindrome(string s) {
    if (s.empty()) return "";
    int start = 0, maxLen = 1;

    auto expandFromCenter = [&](int left, int right) {
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            left--; right++;
        }
        int len = right - left - 1;
        if (len > maxLen) {
            maxLen = len;
            start = left + 1;
        }
    };

    for (int i = 0; i < s.size(); i++) {
        expandFromCenter(i, i);       // odd length palindrome
        expandFromCenter(i, i + 1);   // even length palindrome
    }
    return s.substr(start, maxLen);
}
🟡 Longest Common SubsequenceMedium 
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1[i-1] == text2[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
            else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}
🔴 Edit DistanceHard 
int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1[i-1] == word2[j-1]) dp[i][j] = dp[i-1][j-1];
            else dp[i][j] = 1 + min({dp[i-1][j-1], dp[i-1][j], dp[i][j-1]});
        }
    }
    return dp[m][n];
}
Interview Point: String DP problems mein 2D table banao jahan dp[i][j] = "pehli string ke first i characters aur dusri ke first j characters" ka answer represent kare — ye base setup 80% string-DP problems mein reuse hota hai.

Pattern 7 — Backtracking on Strings

Signal: "generate all permutations", "letter combinations", "all valid combinations" — jahan saare possible outcomes explore karne hon.

Template

void backtrack(string& current, /* other params */) {
    if (/* base case complete */) {
        result.push_back(current);
        return;
    }
    for (/* har choice */) {
        current.push_back(choice);      // choose karo
        backtrack(current, ...);         // explore karo
        current.pop_back();              // un-choose karo (backtrack)
    }
}
🟡 Letter Combinations of a Phone NumberMedium 
vector<string> letterCombinations(string digits) {
    if (digits.empty()) return {};
    vector<string> mapping = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    vector<string> result;
    string current;

    function<void(int)> backtrack = [&](int index) {
        if (index == digits.size()) {
            result.push_back(current);
            return;
        }
        string letters = mapping[digits[index] - '0'];
        for (char c : letters) {
            current.push_back(c);
            backtrack(index + 1);
            current.pop_back();
        }
    };

    backtrack(0);
    return result;
}
🟡 Generate ParenthesesMedium 
vector<string> generateParenthesis(int n) {
    vector<string> result;
    string current;

    function<void(int,int)> backtrack = [&](int open, int close) {
        if (current.size() == 2 * n) {
            result.push_back(current);
            return;
        }
        if (open < n) {
            current.push_back('(');
            backtrack(open + 1, close);
            current.pop_back();
        }
        if (close < open) {
            current.push_back(')');
            backtrack(open, close + 1);
            current.pop_back();
        }
    };

    backtrack(0, 0);
    return result;
}
Dhyan dein: Backtracking mein har "choose" ke baad matching "un-choose" (pop_back()) zaroor karo, warna string ki state agle branch ke liye corrupt ho jaayegi.

Pattern 8 — String Matching (KMP Algorithm)

Signal: "find all occurrences of pattern in text efficiently", jab naive O(n*m) substring search bohot slow ho.

KMP (Knuth-Morris-Pratt) ek LPS array (Longest Prefix which is also Suffix) banata hai jisse pattern match fail hone par bhi text mein wapas jaane ki zaroorat nahi padti — O(n+m) mein solve ho jaata hai.

🔴 Implement strStr() using KMPHard 
vector<int> computeLPS(string& pattern) {
    int n = pattern.size();
    vector<int> lps(n, 0);
    int len = 0, i = 1;

    while (i < n) {
        if (pattern[i] == pattern[len]) {
            lps[i++] = ++len;
        } else if (len > 0) {
            len = lps[len - 1];
        } else {
            lps[i++] = 0;
        }
    }
    return lps;
}

int strStr(string haystack, string needle) {
    if (needle.empty()) return 0;
    vector<int> lps = computeLPS(needle);
    int i = 0, j = 0;

    while (i < haystack.size()) {
        if (haystack[i] == needle[j]) {
            i++; j++;
            if (j == needle.size()) return i - j;   // match mil gaya
        } else if (j > 0) {
            j = lps[j - 1];
        } else {
            i++;
        }
    }
    return -1;
}
Tip: Interview mein KMP poori tarah likhna rare hota hai, lekin concept samajhna (LPS array kya karta hai aur kyun O(n+m) milta hai) important hai — aksar "explain your approach" pucha jaata hai.

⚠️ Common Mistakes & Interview Tips

  • String comparison mein == use karna bhool jaana (ya galat expect karna ki pointer compare hoga jaise C mein)
  • Repeated string concatenation loop mein karna — O(n²) ho sakta hai; StringBuilder jaisi soch C++ mein += se hi milti hai
  • s[i] - '0' ya s[i] - 'a' bhool jaana character-to-number conversions mein
  • Backtracking mein pop_back() (un-choose) karna bhool jaana
  • Sliding Window mein window ki validity check karna bhool jaana pehle shrink karne se pehle
  • Empty string ya single character edge cases handle na karna
Dhyan dein: String problems mein hamesha socho — "characters ka range kya hai?" (lowercase only? unicode?) — isse frequency array vs HashMap ka decision easy ho jaata hai.

🧠 Quick Revision — Click to Reveal

C++ string mutable hai to Java/Python se kya farak padta hai?
C++ mein tum in-place modify kar sakte ho (reverse, swap) bina extra space liye. Java/Python mein string immutable hai, isliye har modification naya string banata hai (extra space/time).
Anagram check karne ka fastest tareeka kya hai?
Sorting se O(n log n) lagta hai. Frequency array (26 size) se O(n) mein ho jaata hai — dono strings ka character count match karke.
"Expand around center" approach kaam kaise karta hai palindrome ke liye?
Har possible center (n centers for odd length, n-1 gaps for even length) se dono taraf expand karte hain jab tak characters match karein — total O(n²) time, but O(1) space (DP se better space-wise).
Kab Stack use karna chahiye string problems mein?
Jab "matching pairs", "nested structure", ya "most recent unmatched item chahiye" jaisa pattern ho — jaise valid parentheses, decode string, ya removing adjacent duplicates.
