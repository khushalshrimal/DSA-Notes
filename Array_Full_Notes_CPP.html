📘 Part A — Basic Theory & Concepts

Pehle fundamentals clear karo — array memory mein kaise store hota hai, static vs dynamic, basic operations. Ye foundation Part B ke patterns samajhne ke liye zaroori hai.

1️⃣ Array kya hota hai?

Array ek linear data structure hai jisme same type ke elements contiguous (ek saath, continuous) memory locations mein store hote hain. Har element ka apna index hota hai (0 se shuru).

Index: 0 1 2 3 4 ┌─────┬─────┬─────┬─────┬─────┐ Array: │ 10 │ 20 │ 30 │ 40 │ 50 │ └─────┴─────┴─────┴─────┴─────┘ Base Address: 2000 2004 2008 2012 2016 (int = 4 bytes)
Samjho ise aise: Array ek apartment building ki tarah hai jisme har flat (index) ek fix size ka hai aur sab ek row mein lagatar hain. Isliye flat number pata ho to seedha wahan pahunch sakte ho (O(1) access) — building ke gate se ginte hue jaane ki zaroorat nahi.
Tip: Array ka address formula: address(i) = base_address + i * size_of_element — isi wajah se index se O(1) mein access milta hai.

2️⃣ Memory Layout & Why O(1) Access

Kyunki elements contiguous hain aur har element ka size fix hai, compiler direct formula se kisi bhi index ka address nikal leta hai — isliye arr[5] access karne mein utna hi time lagta hai jitna arr[0] access karne mein.

Dhyan dein: Ye O(1) access sirf tab tak hai jab tak index valid range mein ho. Out-of-bounds access C++ mein undefined behavior deta hai (crash ya garbage value) — koi automatic error nahi aata jaise Python mein aata hai.

3️⃣ Static Array vs Dynamic Array (vector)

Static Array (fixed size)

int arr[5] = {10, 20, 30, 40, 50};
int arr2[5];  // size fix, compile time pe decide hoti hai

Dynamic Array — vector (C++ STL)

#include <vector>
using namespace std;

vector<int> v;              // empty vector
v.push_back(10);            // end mein insert — amortized O(1)
v.push_back(20);
v.pop_back();                // end se delete — O(1)
v.size();                    // current size
v[2];                        // index access — O(1)

vector<int> v2(5, 0);        // size 5, sab 0 se initialize
PropertyStatic ArrayVector (Dynamic)
SizeFixed, compile-timeGrow/shrink runtime mein
MemoryStack (usually)Heap mein manage hota hai
Resize costPossible nahiAmortized O(1) push_back
Tip: LeetCode par 90% questions mein vector<int> hi milega — isi se comfortable ho jao. Internally jab vector full ho jaata hai, capacity double ho jaati hai (isliye push_back amortized O(1) hai, har baar O(n) nahi).

4️⃣ Basic Operations

Traversal

for (int i = 0; i < arr.size(); i++) {
    cout << arr[i] << " ";
}
// range-based (cleaner)
for (int x : arr) cout << x << " ";
➕ Insertion — Beginning / End / Position 
// End mein insert — O(1) amortized
arr.push_back(60);

// Beginning mein insert — O(n), sab shift karna padta hai
arr.insert(arr.begin(), 5);

// Position pe insert — O(n)
arr.insert(arr.begin() + 2, 25);
➖ Deletion — Beginning / End / Position 
// End se delete — O(1)
arr.pop_back();

// Beginning se delete — O(n)
arr.erase(arr.begin());

// Position se delete — O(n)
arr.erase(arr.begin() + 2);
Dhyan dein: Array/vector mein beginning ya middle se insert/delete O(n) hota hai kyunki baaki elements shift karne padte hain — ye Linked List se bada difference hai.
🔍 Searching — Linear & Binary Search 
// Linear Search — O(n), kisi bhi array pe
int linearSearch(vector<int>& arr, int key) {
    for (int i = 0; i < arr.size(); i++)
        if (arr[i] == key) return i;
    return -1;
}

// Binary Search — O(log n), SORTED array pe hi chalta hai
int binarySearch(vector<int>& arr, int key) {
    int lo = 0, hi = arr.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] == key) return mid;
        else if (arr[mid] < key) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
Tip: mid = lo + (hi-lo)/2 use karo, (lo+hi)/2 nahi — bade arrays mein integer overflow se bachne ke liye.

5️⃣ 2D Arrays / Matrix

// Static 2D array
int matrix[3][4];

// Dynamic — vector of vectors
vector<vector<int>> grid(3, vector<int>(4, 0));  // 3x4, sab 0

// Traversal
for (int i = 0; i < grid.size(); i++) {
    for (int j = 0; j < grid[0].size(); j++) {
        cout << grid[i][j] << " ";
    }
}
grid[i][j] j→ 0 1 2 3 i↓ 0 [ 1 ] [ 2 ] [ 3 ] [ 4 ] 1 [ 5 ] [ 6 ] [ 7 ] [ 8 ] 2 [ 9 ] [10 ] [11 ] [12 ]

Common patterns: row-wise/column-wise traversal, spiral traversal, transpose, rotate matrix 90°, diagonal traversal.

Pattern 1 — Two Pointers

Signal: Sorted array, "pair with target sum", palindrome check — jab 2 positions ko ek saath (opposite ends se ya same direction mein) move karna ho.

Template

int left = 0, right = arr.size() - 1;
while (left < right) {
    // condition check karo, left++ ya right-- karo
}
🟢 Two Sum II (sorted array)Easy 
vector<int> twoSum(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left < right) {
        int sum = nums[left] + nums[right];
        if (sum == target) return {left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return {};
}
🟢 Valid PalindromeEasy 
bool isPalindrome(string s) {
    int left = 0, right = s.size() - 1;
    while (left < right) {
        if (!isalnum(s[left])) { left++; continue; }
        if (!isalnum(s[right])) { right--; continue; }
        if (tolower(s[left]) != tolower(s[right])) return false;
        left++; right--;
    }
    return true;
}
🟡 Container With Most WaterMedium

Chhoti height wale pointer ko andar move karo — usi mein sudhaar ka chance hai.

int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int maxWater = 0;
    while (left < right) {
        int water = min(height[left], height[right]) * (right - left);
        maxWater = max(maxWater, water);
        if (height[left] < height[right]) left++;
        else right--;
    }
    return maxWater;
}
🟡 3SumMedium

Sort karo, phir har element ko fix karke baaki 2 elements Two Pointer se dhundo.

vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> result;

    for (int i = 0; i < nums.size(); i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue; // duplicate skip
        int left = i + 1, right = nums.size() - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                result.push_back({nums[i], nums[left], nums[right]});
                while (left < right && nums[left] == nums[left+1]) left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++; right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return result;
}
Interview Point: Two Pointers mostly sorted array pe hi kaam karta hai — agar array sorted nahi hai to pehle sort karne ka time O(n log n) add hoga.

Pattern 2 — Sliding Window

Signal: "subarray/substring of size k", "longest/shortest subarray with condition" — jab ek contiguous window ko slide karna ho bina restart kiye.

Template (variable size window)

int left = 0;
for (int right = 0; right < arr.size(); right++) {
    // window mein arr[right] add karo

    while (/* window invalid ho gayi */) {
        // window se arr[left] remove karo
        left++;
    }
    // yahan window valid hai — answer update karo
}
🟢 Maximum Sum Subarray of Size KEasy 
int maxSumSubarray(vector<int>& arr, int k) {
    int windowSum = 0, maxSum = 0;
    for (int i = 0; i < arr.size(); i++) {
        windowSum += arr[i];
        if (i >= k - 1) {
            maxSum = max(maxSum, windowSum);
            windowSum -= arr[i - k + 1];  // window ka pehla element hatao
        }
    }
    return maxSum;
}
🟡 Longest Substring Without Repeating CharactersMedium 
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> lastSeen;
    int left = 0, maxLen = 0;

    for (int right = 0; right < s.size(); right++) {
        if (lastSeen.count(s[right]) && lastSeen[s[right]] >= left) {
            left = lastSeen[s[right]] + 1;
        }
        lastSeen[s[right]] = right;
        maxLen = max(maxLen, right - left + 1);
    }
    return maxLen;
}
🟡 Minimum Size Subarray SumMedium 
int minSubArrayLen(int target, vector<int>& nums) {
    int left = 0, sum = 0, minLen = INT_MAX;
    for (int right = 0; right < nums.size(); right++) {
        sum += nums[right];
        while (sum >= target) {
            minLen = min(minLen, right - left + 1);
            sum -= nums[left];
            left++;
        }
    }
    return minLen == INT_MAX ? 0 : minLen;
}
Tip: Fixed-size window (size k pata hai) vs Variable-size window (condition ke hisaab se shrink/grow) — dono ka template thoda alag hota hai, dono pehchan na practice karo.

Pattern 3 — Prefix Sum

Signal: "range sum query", "subarray sum equals k", multiple range queries — jahan baar baar sum nikalna ho.

Template

vector<int> prefix(arr.size() + 1, 0);
for (int i = 0; i < arr.size(); i++) {
    prefix[i + 1] = prefix[i] + arr[i];
}
// range [l, r] ka sum = prefix[r+1] - prefix[l]
🟢 Range Sum Query — ImmutableEasy 
class NumArray {
    vector<int> prefix;
public:
    NumArray(vector<int>& nums) {
        prefix.resize(nums.size() + 1, 0);
        for (int i = 0; i < nums.size(); i++)
            prefix[i + 1] = prefix[i] + nums[i];
    }
    int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];
    }
};
🟡 Subarray Sum Equals KMedium

Prefix Sum + HashMap combo — jitni baar (currentSum - k) pehle dikha hai, utne subarrays milte hain.

int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> freq;
    freq[0] = 1;   // empty prefix
    int sum = 0, count = 0;

    for (int num : nums) {
        sum += num;
        if (freq.count(sum - k)) count += freq[sum - k];
        freq[sum]++;
    }
    return count;
}
Interview Point: Prefix Sum ka combo HashMap ke saath ("Subarray Sum Equals K" jaisa) bohot common trick hai — O(n²) brute force ko O(n) mein badal deta hai.

Pattern 4 — Kadane's Algorithm

Signal: "maximum subarray sum", "maximum product subarray" — contiguous subarray ka best sum/product dhundna ho.

Template

int currentSum = 0, maxSum = INT_MIN;
for (int num : arr) {
    currentSum = max(num, currentSum + num);  // naya subarray shuru karo ya extend karo
    maxSum = max(maxSum, currentSum);
}
🟡 Maximum SubarrayMedium 
int maxSubArray(vector<int>& nums) {
    int currentSum = nums[0], maxSum = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        currentSum = max(nums[i], currentSum + nums[i]);
        maxSum = max(maxSum, currentSum);
    }
    return maxSum;
}
Tip: Idea: agar current running sum negative ho jaaye, to usse aage carry karne ka koi fayda nahi — naye index se fresh shuru karo.
🟡 Maximum Product SubarrayMedium

Negative number se multiply hone par max aur min swap ho sakte hain — isliye dono track karo.

int maxProduct(vector<int>& nums) {
    int maxProd = nums[0], minProd = nums[0], result = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        if (nums[i] < 0) swap(maxProd, minProd);
        maxProd = max(nums[i], maxProd * nums[i]);
        minProd = min(nums[i], minProd * nums[i]);
        result = max(result, maxProd);
    }
    return result;
}

Pattern 5 — Binary Search (on Array & on Answer)

Signal: "sorted array", "search in rotated array", "find peak element", "minimize the maximum" — jahan search space ko half-half karke narrow kar sakte ho.
🟢 Binary Search (basic)Easy 
int search(vector<int>& nums, int target) {
    int lo = 0, hi = nums.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
🟡 Search in Rotated Sorted ArrayMedium

Har step pe pehchano kaunsa half sorted hai, phir target us half mein hai ya nahi check karo.

int search(vector<int>& nums, int target) {
    int lo = 0, hi = nums.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] == target) return mid;

        if (nums[lo] <= nums[mid]) {          // left half sorted hai
            if (nums[lo] <= target && target < nums[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {                               // right half sorted hai
            if (nums[mid] < target && target <= nums[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}
🟡 Koko Eating Bananas (Binary Search on Answer)Medium

Jab direct answer search na ho, to "answer range" pe binary search karo — feasibility check karke.

bool canFinish(vector<int>& piles, int speed, int h) {
    long hours = 0;
    for (int p : piles) hours += (p + speed - 1) / speed;  // ceil division
    return hours <= h;
}

int minEatingSpeed(vector<int>& piles, int h) {
    int lo = 1, hi = *max_element(piles.begin(), piles.end());
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canFinish(piles, mid, h)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
Interview Point: "Binary Search on Answer" ek advanced but bohot powerful sub-pattern hai — jab bhi "minimize the maximum" ya "maximize the minimum" dikhe, ye try karo.

Pattern 6 — Sorting-based Patterns

Signal: "merge intervals", "sort colors", "kth largest/smallest" — jahan sorting se problem simplify ho jaati hai.
🟡 Merge IntervalsMedium 
vector<vector<int>> merge(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end());
    vector<vector<int>> result;

    for (auto& interval : intervals) {
        if (result.empty() || result.back()[1] < interval[0]) {
            result.push_back(interval);
        } else {
            result.back()[1] = max(result.back()[1], interval[1]);
        }
    }
    return result;
}
🟡 Sort Colors (Dutch National Flag)Medium

3-way partitioning — ek hi pass mein 0,1,2 ko sahi jagah rakh do, extra space bina.

void sortColors(vector<int>& nums) {
    int low = 0, mid = 0, high = nums.size() - 1;
    while (mid <= high) {
        if (nums[mid] == 0) { swap(nums[low], nums[mid]); low++; mid++; }
        else if (nums[mid] == 1) { mid++; }
        else { swap(nums[mid], nums[high]); high--; }
    }
}
🟡 Kth Largest ElementMedium

Simple approach: sort karke n-k index return karo. Optimal: min-heap ya quickselect.

int findKthLargest(vector<int>& nums, int k) {
    sort(nums.begin(), nums.end());
    return nums[nums.size() - k];
}
// Time: O(n log n). Quickselect se average O(n) mein ho sakta hai.

Pattern 7 — Hashing

Signal: "two sum", "duplicate check", "frequency count", "group by" — jahan O(1) lookup se O(n) mein solve ho sake.
🟢 Two SumEasy 
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> seen;   // value -> index
    for (int i = 0; i < nums.size(); i++) {
        int need = target - nums[i];
        if (seen.count(need)) return {seen[need], i};
        seen[nums[i]] = i;
    }
    return {};
}
🟢 Contains DuplicateEasy 
bool containsDuplicate(vector<int>& nums) {
    unordered_set<int> seen;
    for (int num : nums) {
        if (seen.count(num)) return true;
        seen.insert(num);
    }
    return false;
}
🟡 Top K Frequent ElementsMedium 
vector<int> topKFrequent(vector<int>& nums, int k) {
    unordered_map<int, int> freq;
    for (int num : nums) freq[num]++;

    priority_queue<pair<int,int>> pq;  // max-heap by frequency
    for (auto& [num, count] : freq) pq.push({count, num});

    vector<int> result;
    while (k--) {
        result.push_back(pq.top().second);
        pq.pop();
    }
    return result;
}
Tip: Jab bhi "O(n²) brute force" soch rahe ho aur ek loop mein "kya ye pehle dikha tha?" jaisa sawaal aa raha ho — turant HashMap/HashSet use karne ka socho.

Pattern 8 — In-place Array Manipulation

Signal: "rotate array", "move zeros", "remove duplicates from sorted array — in place" — jahan O(1) extra space mein array ko modify karna ho.
🟡 Rotate ArrayMedium

Trick: pura array reverse karo, phir pehle k aur baaki n-k ko alag-alag reverse karo.

void rotate(vector<int>& nums, int k) {
    k = k % nums.size();
    reverse(nums.begin(), nums.end());
    reverse(nums.begin(), nums.begin() + k);
    reverse(nums.begin() + k, nums.end());
}
🟢 Move ZeroesEasy 
void moveZeroes(vector<int>& nums) {
    int insertPos = 0;
    for (int i = 0; i < nums.size(); i++) {
        if (nums[i] != 0) {
            swap(nums[insertPos], nums[i]);
            insertPos++;
        }
    }
}
🟢 Remove Duplicates from Sorted ArrayEasy 
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
Interview Point: "In-place" ka matlab O(1) extra space — ye pattern aksar slow-fast pointer (same array ke andar) use karta hai, Linked List wale fast-slow se concept similar hai.

Pattern 9 — Cyclic Sort

Signal: "numbers from 1 to n", "missing number", "duplicate number" — jab array mein ek fix range (1 to n) ke numbers hon.

Template

int i = 0;
while (i < nums.size()) {
    int correctIdx = nums[i] - 1;
    if (nums[i] != nums[correctIdx]) {
        swap(nums[i], nums[correctIdx]);
    } else {
        i++;
    }
}
// ab har number apni sahi jagah (index = value-1) pe hoga
🟢 Find the Missing NumberEasy 
int missingNumber(vector<int>& nums) {
    int i = 0, n = nums.size();
    while (i < n) {
        int correctIdx = nums[i];
        if (nums[i] < n && nums[i] != nums[correctIdx]) {
            swap(nums[i], nums[correctIdx]);
        } else {
            i++;
        }
    }
    for (int j = 0; j < n; j++)
        if (nums[j] != j) return j;
    return n;
}
🟡 Find All Duplicates in an ArrayMedium 
vector<int> findDuplicates(vector<int>& nums) {
    int i = 0;
    while (i < nums.size()) {
        int correctIdx = nums[i] - 1;
        if (nums[i] != nums[correctIdx]) swap(nums[i], nums[correctIdx]);
        else i++;
    }
    vector<int> result;
    for (int j = 0; j < nums.size(); j++)
        if (nums[j] != j + 1) result.push_back(nums[j]);
    return result;
}
Tip: Cyclic Sort O(n) time aur O(1) space mein "1 to n" range ke missing/duplicate problems solve kar deta hai — HashSet approach se better (jo O(n) space leta hai).

⚠️ Common Mistakes & Interview Tips

  • Array index out of bounds — C++ mein silent crash/garbage value deta hai, error nahi
  • (lo+hi)/2 use karna binary search mein — overflow ho sakta hai, lo + (hi-lo)/2 use karo
  • Sliding window mein left pointer ko galat condition mein move karna
  • 2D array traversal mein rows/cols ki size confuse karna — hamesha grid.size() aur grid[0].size() check karo
  • In-place modification karte waqt original array ke size/index invalidate ho jaana (especially erase() loop ke andar)
  • Sorting-based approach use karte waqt time complexity bhool jaana (O(n log n) add hota hai)
Dhyan dein: "Can you do it in O(1) space?" — ye follow-up interviewer aksar pucchta hai. Pehle apna normal solution do, phir in-place optimize karne ki koshish karo.

🧠 Quick Revision — Click to Reveal

Two Pointers aur Sliding Window mein kya farak hai?
Two Pointers mein pointers alag directions se move ho sakte hain (opposite ends se). Sliding Window mein ek "window" hoti hai jo hamesha ek direction mein grow/shrink hoti hai (contiguous range maintain karta hai).
Prefix Sum kab use karna chahiye?
Jab multiple range-sum queries poochi jaayein, ya "subarray sum = k" jaisa pattern ho. Ek baar O(n) mein prefix array bana lo, phir har query O(1) mein answer ho jaati hai.
Cyclic Sort sirf kab kaam karta hai?
Jab array mein numbers ek fix range (jaise 1 to n, ya 0 to n-1) mein hon. Random range ke numbers ke liye ye kaam nahi karega.
Kadane's Algorithm ka core idea kya hai?
Agar current running sum negative ho jaaye, to usse aage carry karne ka fayda nahi — naye index se fresh subarray shuru karo. Isse O(n) mein max subarray sum mil jaata hai.
